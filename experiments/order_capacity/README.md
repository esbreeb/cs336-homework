# H1 toy：叠加几何有没有路径依赖

这一级只回答 go/no-go，不碰 GPT-2，也不需要 5090。

假设 H1：两组统计性质完全相同的特征，先学的那一组会占住专用维度，并且在之后的混合训练里仍占着。如果这个差距在混合训练后掉回同时训练的种子噪声里，顺序效应没有留下来，主线改去看效率（H3），而不是继续往机制存活上加码。

## 模型

Elhage 等人的绑权 ReLU 自编码器。`W` 形状是 `(n_hidden, n_features)`：

```
h = x Wᵀ
y = ReLU(h W + b)
```

特征独立同分布：以概率 `p` 激活，激活值 `Uniform(0, 1)`，重要性全部为 1。两组之间唯一的差别是引入顺序。

特征维度用 Elhage 的定义：

```
D_i = ||W_i||² / Σ_j (Ŵ_i · W_j)²
```

列范数低于 0.05 的特征记为未学，`D_i = 0`。专用基向量是 1，对径成对是 1/2。

## 课程

32 个特征，对半分成 A、B。主设定用 24 个隐藏维：够把先学的 16 个特征各放进一个专用方向，同时剩下 8 维给后学的特征做叠加。16 维瓶颈做不到这件事（先学的一组若占满专用维，后学的一组没有剩余维度），所以 16 维只做敏感性，不做判定。

| 日程 | 阶段 1（1000 步） | 阶段 2（8000 步） |
| --- | --- | --- |
| `ab` | 只训练 A | A、B 一起训练 |
| `ba` | 只训练 B | A、B 一起训练 |
| `sim` | A、B 一起训练 | 继续一起训练 |

阶段 1 的步数取自一次探测：种子 0、日程 `ab` 在第 400 步时先学组的 `D` 已经到 0.90。正式阶段 1 取 1000 步，落在这个平台之后。阶段 2 是阶段 1 的 8 倍，用来区分“还没来得及忘掉”和“混合训练之后仍保留”。探测本身不是结果。

未引入的特征不进损失，输入也置零，对应列拿不到梯度。优化器状态从阶段 1 带到阶段 2，不重置。同一颗种子下三种日程共用同一套初始权重和同一条随机数流。

## 滞后指数和判定

```
Λ = (D_early − D_late) / (D_early + D_late)
ΔD = D_early − D_late
```

`sim` 没有顺序。它在终点上的 `D_A − D_B`（以及同样写法的 Λ）跨种子的波动，就是噪声基线。

判定看混合阶段的终点，不看阶段 1。两条有顺序的日程都要同时超过下面两条线，才算 go：

```
mean(Λ)  > max(0.15, mean(|Λ_sim|) + 2 σ_Λ)
mean(ΔD) > max(0.10, 2 σ_ΔD)
```

阶段 1 结束时先学组的平均 `D` 不到 0.75，记为 `invalid`（课程没有形成，不能解释成反证）。

几何标签只作描述，不参与判定：

- `packing`：先学组仍然专用（`D ≥ 0.75`），后学组学会了但维度是分数
- `exclusion`：先学组专用，后学组基本没学会
- `symmetric`：两组维度差不超过 0.10

## 结果

判定用的是混合阶段的终点，不是阶段 1。10 颗种子。

阶段 1 结束时先学组的维度是 0.997，课程本身成立。混合一开始，专用维度就交回去了：阶段 1 结束时两组维度差是 0.995，再训练 200 步就掉到大约 0.10。之后直到第 9000 步，这个缝不再扩大，也不再消失。终点上维度之和是 23.99，24 个隐藏维被装满，对称装箱是每个特征 0.75。两组都在这个叠加解附近。

| 日程 | 先学组 D | 后学组 D | 维度差 | 滞后指数 Λ |
| --- | ---: | ---: | ---: | ---: |
| A 然后 B | 0.795 | 0.705 | 0.090 ± 0.050 | 0.060 |
| B 然后 A | 0.809 | 0.690 | 0.119 ± 0.048 | 0.079 |
| 同时训练 | 0.749 | 0.750 | −0.000 ± 0.046 | 0.000 |

门槛是 Λ > 0.15 且维度差 > 0.10，两个顺序都要过。A→B 的维度差是 0.090，没过；两条日程的 Λ 都没过。判定 **no-go**。

同时训练的种子噪声（维度差的标准差 0.046）和这条残差同一量级。残差的方向跟引入顺序一致，跨种子平均之后不等于零，所以它不是某一次初始化的偶然；它也不是「专用维度还占着」。两组的重建损失都在 0.0002 附近，零预测基线是 0.0167，后学的特征没有被丢掉。

按方案，主线不再靠「顺序决定容量分配」往下走。同一台机器上接着测了效率：按教师自己的习得顺序蒸馏，是否比 progressive distillation 省学生步数。

教师是 20 维、重要性按 1、1/4、1/16、1/64 分四档的同一个玩具模型。它确实有发育顺序：前 24 个特征在第 300 步以前学会，最弱的 8 个平均要到第 1038 步。两波相差 804 步。学生是 8 维，8 颗种子，两阶段各 2000 步。评价始终是对最终教师全部特征的均方误差。目标是把初始误差降到四分之一。

| 日程 | 到达目标的平均步数 | 未到达的种子 | 终点误差 |
| --- | ---: | ---: | ---: |
| 发育顺序 | 3988 | 6/8 | 0.00406 |
| progressive | 3300 | 3/8 | 0.00388 |
| 逆序 | 3238 | 2/8 | 0.00385 |
| 直接对齐最终教师 | 2213 | 1/8 | 0.00381 |

速度判定是 **inconclusive**：发育顺序有一半以上的种子没跨过目标，规则不允许在这种审查下宣布 go。方向并不含糊。8 颗种子里，发育顺序的终点误差都高于 progressive，配对差是 +0.000181（标准误 0.000068）。最省步数的是从第一步就对齐最终教师。按发育顺序安排目标，在这个玩具里没有省下 token。

5090 上的合成电路和 GPT-2 蒸馏这次没有跑。玩具结果没有给出把那两级当作主线的理由。
